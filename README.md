☕ Coffee Shop Website

<br>A responsive coffee shop landing page built with HTML, CSS, and JavaScript. This project was designed to practice front-end fundamentals: clean structure, styling consistency, and debugging for cross-browser compatibility.

<br>✨ Features
<br>	•	Semantic HTML structure for accessibility and clarity
<br>	•	Responsive CSS layout (flexbox/grid) for desktop and mobile
<br>	•	JavaScript interactivity for simple dynamic elements
<br>	•	Debugged and tested across multiple browsers
<br>	•	Managed with GitHub version control (commits and branches)

<br>🛠️ Tech Stack
<br>	•	HTML5
<br>	•	CSS3 (flexbox, grid, media queries)
<br>	•	JavaScript (basic DOM manipulation)
<br>	•	Git & GitHub

<br>📚 What I Learned
<br>	•	Structuring reusable, maintainable CSS
<br>	•	Debugging responsive layouts
<br>	•	Practicing GitHub workflows (commits, branching, issue tracking)
